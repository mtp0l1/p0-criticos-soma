    Para baixar

    Tudo o que a engenharia precisa para levar o sistema para o repositório.

    • soma-design-system.zipPacote completo: tokens, código-fonte, bundle, tipos e documentação
    • tokens.jsonFonte única dos tokens
    • tokens.cssVariáveis CSS e classes de texto
    • index.d.tsTipos e props de cada componente
    • tailwind.preset.jsPreset Tailwind com as escalas fechadas
    • src/index.tsExportações; os componentes ficam em src/ui e src/soma
    • bundle.jsTudo em window.Soma, para protótipo sem build (React 18)
    • bundle.cssTailwind compilado com o preset

    O passo a passo de instalação, as convenções e a tabela de estados estão em Para engenharia.
